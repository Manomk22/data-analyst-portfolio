# Manojkumar — Data Analyst Portfolio

Angular 17 portfolio site, deployed on Vercel.

## Portfolio focus
- SQL and PostgreSQL
- Excel and Excel VBA reporting automation
- Power BI, DAX, KPI reporting, and dashboards
- Data collection, enrichment, validation, and cleansing

## Featured projects
1. Coffee Sales Analysis — Power BI
2. Hypermarket Sales Analysis — Power BI
3. Automated Sales MIS Reporting System — PostgreSQL, SQL, Excel VBA, Power BI (in progress)

## Run locally
```bash
npm ci
npm start
```
Open `http://localhost:4200/`.

## Build
```bash
npm run build
```
